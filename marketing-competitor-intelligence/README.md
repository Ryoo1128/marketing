# Marketing Competitor Intelligence

광고 라이브러리 기반 경쟁사 캠페인·소재 분석 웹사이트 프로토타입입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 접속.

## Vercel 배포

1. 이 폴더를 GitHub 저장소에 업로드합니다.
2. Vercel에서 저장소를 Import합니다.
3. Framework Preset은 Next.js로 자동 인식됩니다.
4. Deploy를 클릭합니다.

## 포함 기능

- Dashboard
- Creative Library 검색 및 플랫폼 필터
- Creative Detail AI 분석 화면
- AI Insights
- 실제 `.pptx` 파일 다운로드

## 현재 범위

광고 데이터는 예시 데이터입니다. 실제 자동 수집을 위해서는 Meta Ad Library API, Google Ads Transparency Center, 네이버 광고 데이터 수집용 서버/API 연결이 필요합니다.
